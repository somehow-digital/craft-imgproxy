---
title: Thumbnails
description: Generate the Control Panel thumbnails with imgproxy.
---

By default, the thumbnails of assets in the Control Panel come from imgproxy, as `webp`. Change the format with **Thumbnail Format**.

Turn off **Thumbnails** to handle them like any other image transform instead, which follows **Transforms**. With both off, Craft generates them.

Assets that imgproxy can't fetch, such as those in volumes without public URLs, are left to Craft.
