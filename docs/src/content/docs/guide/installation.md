## Requirements

- Craft CMS 5.8.0 or later
- PHP 8.2 or later
- imgproxy 3.0 or later

## Install

Install the plugin from the [**Plugin Store**](https://plugins.craftcms.com/imgproxy) in the Control Panel, or with [Composer](https://packagist.org/packages/somehow-digital/craft-imgproxy):

```bash
composer require somehow-digital/craft-imgproxy
php craft plugin/install imgproxy
```
